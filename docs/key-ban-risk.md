# v1.2.7-keyban.1 试用说明

基于上游 v1.2.7（28f2f1f6），仅发布到 KomachiSion/StrongholdAssistant。保留上游功能，重新接入旧 fork 的关键干员推荐逻辑。

## 推荐等级和排序

编辑阵容时，固定成员、任选组和阶段成员均可设置「关键 / 推荐 / 普通」。旧 key:true 保持关键，旧普通成员仍普通，不自动猜测推荐。两个字段同时存在时以关键优先。

推荐按成型阵容比较，先比较关键缺失数，再推荐缺失数，再目标盟约不完整数，最后普通缺失数；相同条件下已设置关键的阵容优先，其余保持原序。不会因很多普通禁用，把关键缺失误排到前面。卡片分开显示三类禁用，不把「当前选择」等同于推荐。

任选 N 组优先遵守替代语义：剩余候选满足 N，不因某个关键候选被禁处罚，只展示替代提示；不足 N 时，按能补足缺口的最低损失候选计数，而不是计所有被禁候选，也不会由仍可用的关键成员抬高缺口等级。真正不可替代的核心请放固定成员，而不要放进任选组。阶段配置仍用于阶段跟踪，不作为开局成型阵容排序依据。

未完成识别时明确提醒信息不完整；「暂未发现禁用冲突」不代表阵容强度保证。尚未设置关键的阵容会提示配置。

## 新局清理

明确重置对局，或宿主成功识别新开局 / 敌人变化 / 盟约变化时，清除旧目标和阶段，清理目标派生跟踪，并同步保存和更新界面。同局补扫、识别失败不清目标。完全相同信息且未识别到开局页时无法可靠区分两局，请使用重置对局。

## 数据与分享

升级前请关闭所有旧版实例，备份整个 `%AppData%\StrongholdAssistant`，再将 ZIP 解压到新目录启动。不要覆盖该用户数据目录。本版沿用原数据目录并新增可选 recommended 字段，不自动修改旧方案的优先级。上游可能存在其他数据迁移，回退请使用升级前完整备份。

不含推荐字段的方案继续输出原 SA1–SA4 分享码；含推荐字段输出 SA5，只有本 fork 新版支持，旧版或上游暂不保证能导入。不要将 SA5 作为兼容上游的分享格式。应用内更新关闭，避免自动覆盖为缺少定制功能的上游版本。

## 验证与限制

自动化涵盖优先级排序、任选组、分享码往返与旧格式、配置保存重载、新局目标清理及同局/失败识别保留。发布流程运行前端类型检查/构建、Windows .NET 测试、自包含 x64 打包和启动存活检查。CI 成功不等同于真实游戏 OCR 或人工 UI 验收；请试用后反馈。

包为 Windows x64，不是 32 位 x86。自包含 .NET，无需另外安装 .NET 运行时；界面依赖 Windows 11 通常自带的 WebView2，缺失时仍需安装。
